# Bé Học Toán (Lớp 1–5)

Trang web luyện toán tiểu học từ lớp 1 đến lớp 5, có menu chọn lớp. Mỗi lớp có các chủ đề theo chương trình: đếm số, cộng trừ nhân chia, xem đồng hồ, chu vi, diện tích, phân số, số thập phân, tỉ số phần trăm, đổi đơn vị.

Chỉ có một file tĩnh `index.html`, mở trực tiếp bằng trình duyệt hoặc deploy lên Cloudflare Pages (không cần build).
